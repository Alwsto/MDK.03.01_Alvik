В форме входа выберите учётную запись. Общий пароль только для демонстрационного режима — **StudentLoad2026!**.

| Логин | Роль | Доступ |
|---|---|---|
| methodist | Методист | Просмотр, создание, изменение и удаление нагрузки, свод и экспорт |
| admin | Заведующий отделением | Просмотр и изменение нагрузки, свод и экспорт |
| dispatcher | Диспетчер | Просмотр общей нагрузки и свод |
| teacher | Преподаватель | Просмотр собственной нагрузки |
